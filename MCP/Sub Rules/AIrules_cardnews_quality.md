# 카드뉴스 품질 규칙

- 3줄요약의 각 줄은 앞뒤 줄을 읽지 않아도 이해되는 독립 완결형으로 작성한다.
- 한 문장을 줄 단위로 쪼개지 않는다.
- `~두고`, `~대해`, `~관련해`, `~위해`, `~하며`, `~지만`처럼 다음 줄에 술어가 이어지는 형태로 줄을 끝내지 않는다.
- SNS 게시 전에는 Canva 결과 PNG만 확인하지 말고, 필수 이미지 슬롯(`TOON_1~4`, 차트, 구름 등)이 실제 데이터 필드에 포함됐는지 확인한다.
- 필수 이미지가 비었거나 3줄요약이 독립 완결형이 아니면 게시하지 않고 재생성한다.
- 자동 게시 파이프라인에는 게시 전 품질검사 단계를 둔다. 실패 시 SNS 업로드를 차단하고 성공/실패 스레드에 사유를 남긴다.
