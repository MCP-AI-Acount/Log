## 실패 분류 체계 (A/B/C)

### A — 정상 회복 예측 (일시적)
- **원인**: 429 rate limit, 503 일시 과부하
- **조치**: curfew 시간 기록 후 패스. 타이머 종료 시 자동 복귀. **재시도 없음.**

### B — 시스템 결함
- **기준**: 한 배치 내 개별 건 단위 누적 카운트, **3회 도달 시 트리거**
- 건별 실패(재시도 포함) 모두 카운트
- 예: 건1 실패+건1재시도 실패(2회) + 건2 실패(3회) → B 확정
- **조치**: 해당 배치 즉시 패스. 슬롯 유지.

### C — 원인 불명
- **기준**: 다른 배치에서 부분 실패 1회 = 1건
- **즉시 조치**: 1건 발생 시 해당 LLM 즉시 보류
- **교체 트리거**: 3배치 연속 누적 발생
