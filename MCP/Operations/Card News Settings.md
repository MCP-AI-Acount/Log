# Card News Settings

## 적용 대상
- 카드뉴스 기사형 6종: 외신, 기술, 문화, 경제, 건강, 논문
- 제외: 경제 지표/금융지표 카드, 오늘 날씨 카드
- 공통 코드 파일: `collaboration/card_news_settings.py`

## 공통 템플릿 규칙
- `DATE`: 기존 카드 종류별 기준 시간을 따른다.
  - 외신: 오전 7시 기준
  - 논문: 오전 11시 기준
  - 경제 뉴스: 오후 12시 기준
  - 기술/문화/건강: 오후 5시 기준
- 날짜 표기: `YYYY.MM.DD.(요일) 오전/오후 H시 기준`
  - 예: `2026.05.28.(목) 오후 5시 기준`
- 기사 제목: 10~15자
- 본문: 정확히 3줄
- 본문 각 줄: 15~20자
- 본문 3줄 합계: 최대 60자
- 키워드/주제: 5~8자
- 출처 표기: `릴리즈 날짜와 시간 · 언론사 · 저자`
  - 예: `2026.05.28. 14:30 · Reuters · John Smith`
  - 없는 항목은 생략
  - API 출처가 아니라 실제 언론사/논문 출처를 표기
  - 저자 1명은 이름만, 2명 이상은 `첫 저자 외 N인`

## 토픽별 디테일 유지
- 기사 수, API 소스, 검색 쿼리, 이미지 프롬프트, Canva 필드명, 발행 흐름은 기존 디테일 유지
- 공통 양식만 `card_news_settings.py` 기준으로 적용

## 2026-05-28 기술 뉴스 오류 수정 메모
- 스크린샷 오류: 건강/경제/정치성 AI 기사가 기술 뉴스에 섞이고, 본문 줄이 잘리며, 출처가 언론사명만 표시됨.
- 수정 방향:
  - 기술 뉴스 필터 강화: 건강·금리·정치·로비성 AI 기사 제외
  - 출처 포맷을 `시간 · 언론사 · 저자`로 통일
  - 본문 3줄/15~20자/총 60자 규칙을 공통화
  - `card_news_settings.py`를 외신/토픽 카드 생성 스크립트에서 import

## 일정 스케줄 운영 메모
- Google Calendar MCP에는 현재 실제 이벤트 생성 도구가 노출되어 있지 않으므로 캘린더 이벤트 생성은 이 환경에서 직접 처리 불가.
- 실제 자동 실행 스케줄은 n8n + Cloud Scheduler 기준으로 관리.
- Cloud Scheduler VM 시작:
  - 07:40 KST: 아침 파이프라인용 VM 기동
  - 11:30 KST: 논문 카드용 VM 기동
  - 17:30 KST: 저녁 토픽 카드용 VM 기동
- n8n 토픽 카드:
  - 논문: 11:40 실행 → 12:00 SNS
  - 저녁 토픽: 17:40 실행 → 18:00 SNS
- 스케줄 활성화 실패가 숨겨지지 않도록 `sync_topic_news_daily.sh`, `sync_foreign_news_daily.sh`에서 `publish:workflow` 실패 시 `update:workflow --active=true`를 실행하고 workflow list 확인을 추가.
