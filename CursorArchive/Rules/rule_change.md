## D.D-10. 선택 채점 (선택 위임 시 MUST)

> 층 체계: C.(Core/헌법층 = K·K-8-B) · D.(Detail/절차층 = D·N 규칙)

### 판정 (이 순서로 1회만)

| # | 조건 | 처리 |

| 1 | Yes/No·진행·커밋 확인 | D-10 미적용 |
| 2 | 영향 범위 ≤ 단일 파일·함수 | D-10 미적용 · 경량 대안 |

### 형식

```
**Option A** — raw/max → X.Xpt  ★ 권장
| A축(코드) | 별점 | 가중치 | 점수 |

...
장점: ...  단점: ...
```

- 별점 0.5단위, 5점 만점. 총점 가장 높은 항목에 **★ 권장**. 타협안 1개까지.

### D-10-S. 합성 대안 의무 (Synthesis Option · D-10 적용 시 항시)

**트리거**: D-10이 적용되는 모든 선택 제시 (2개 이상 대안 나열 시).

**MUST**: 마지막 옵션으로 **Option S (합성)** 를 반드시 추가.
- 내용: 앞선 각 대안의 **장점만** 취합한 제3의 접근.
- 형식: `**Option S · 합성** — [A의 장점X] + [B의 장점Y] → [효과]`
- 금지: 각 대안의 단점을 그대로 승계한 "절충(compromise)" 을 합성으로 표기 금지. 합성은 장점 병합이지 중간값이 아님.

## M.M-R. 규칙 제정 시 충돌 검색 의무 (신규 규칙 Write 전 MUST)

> 신규 규칙을 작성하기 전 아래 순서로 F1~F4 충돌을 검색한다.  
> LLM 이해 최적화: 각 규칙은 파일명·섹션 인용 대신 **의미 정의 + 행동 지시**로 작성한다 (M-2 연동).

### 검색 순서

| 단계 | 검색 대상 | 조건 |
|------|----------|------|
| **1** | 신규 규칙이 직접 포인터(참조)하는 규칙들 | 항시 |
| **2** | 신규 규칙과 **같은 레이어**의 규칙 전체 | 항시 |
| **3** | cc_rules/ 전체 + CLAUDE.md (모든 규칙) | 1·2 단계에서 F1~F4 **하나라도 발견** 시만 |

> 1·2 단계에서 문제 없으면 3단계 생략 가능. 발견 즉시 STOP — 3단계로 확장.

### 검색에서 발견된 유형별 처리

| 유형 | 정의 | FAIL 시 처리 |
|------|------|-------------|
| **F1 (모순)** | 두 규칙이 논리상 동시 성립 불가 | Write **STOP** + 유저 확인 필수 |
| **F2 (충돌)** | 계층 우선순위 위반 (상위 규칙과 모순) | Write **STOP** + 유저 확인 필수 |
| **F3 (중복)** | 동일 내용이 다른 파일·섹션에 이미 있음 | 상위 정본 유지, 신규 규칙은 포인터 1줄로 대체 |
| **F4 (구멍)** | MUST만 있고 HOW·집행 경로·트리거가 없음 | HOW 추가 후 Write |

### 집행 주체 (N5 연동)

- F1·F2 FAIL → 유저만 해소 가능. AI 단독 봉합 금지.
- F3 FAIL → 하위 규칙 포인터 교체는 AI 자동 실행 가능 (유저 확인 없어도).
- F4 FAIL → HOW 초안 AI 작성 후 Write — 단, "집행 불가" 판단 시 N5 한계 명시로 대체.

> **집행 경로 현황 (N5)**: M-R 3단계 충돌 검색은 cc-pre-mdc-debate.sh의 C1+ 감지 이후 자기집행. 검색 3단계(포인터→레이어→전체) 자동화 hook 미구현. AI가 신규 규칙 Write 전 직접 실행 의무.
